# Experiment 09 — Shooting Method with Euler

**Problem type:** second-order boundary-value problem.

The differential equation
```text
y'' + 2y' + y = x
```
is rewritten as a first-order system and solved with Euler's method for two trial initial slopes. A linear combination of the two trial solutions is then selected to satisfy the terminal boundary condition.

## Build and run

```bash
make exp09
./exp09
```
